# Bounded checkpointed study continuation

This additive route implements one separately adopted continuation segment over
the unchanged execution-binding-v3 scientific and runtime contracts. It does not
resume an interrupted process or enable the standalone study runners. An
execution profile, genuine operator directive, technical rebind, frozen clean
revision and verified historical eligibility remain mandatory.

## Fixed scope

- Preserve the original prediction-free hold and all four interrupted attempts.
- Import both verified source outputs and the entire eligible fourth-attempt
  prefix, without selecting cells or repeats by their results.
- Execute the fixed remaining suffix through cell 125 in one fresh segment.
  For the present 72-cell prefix, this means 53 whole cells, starting at 73.
  The original service-only stopped cell 73 remains preserved and excluded.
- Do not reopen original source datasets, fit models, change models/thresholds,
  replace adverse observations, extend deadlines or retry a stopped segment.
- Use the original numerical kernels and reducers. H2 remains unsupported by
  its original 28/252 audit failure; all other promised components still require
  complete measurement and reporting.

## Ordered execution gates

1. Independently review the additive implementation and verify the original
   tracked files remain byte-identical. Commit locally only when authorized.
2. Authenticate complete retained catalogs, original receipts and authority,
   source science, every accepted cell, the stopped cell and sampled physical
   history. Seal the index, entire-prefix eligibility and exposure disclosures.
3. Bind an exact profile and envelope to the clean new commit, complete literal
   added-file roster, unchanged original file pins, history records and actual
   operator directive. A metadata dataclass or invented approval is not authority.
4. Invoke only the fixed supervisor with the independent revision/profile/envelope
   pins. It rechecks public binding before opening physical-record outputs and
   launches the root only after AC, Automatic energy mode, disabled Low Power,
   known-workload exclusion and its own sleep assertions pass.
5. The root requires the live parent-owned supervisor pipe before protected work.
   It independently restores history, creates new disjoint records and issues
   live service/client admissions only for the next fixed ordinal.
6. Verify the final 125-cell evidence, all 22 primary checks, all 25 operational
   groups and the separate secondary analyses before final RQ/H synthesis.

The entry point is `scripts/run_study_series_session.py`. Its only arguments are
`--repo-root`, `--expected-revision`, `--expected-profile-sha256`, `--envelope`
and `--expected-envelope-sha256`. It has no command, workload, model, ordinal,
timeout, retry or physical-gate override. Preserve the authenticated interpreter
spelling in subprocess command vectors.

## Failure and reporting boundary

Pre/launch/condition/post/sleep-cleanup records and stdout/stderr are private,
create-only files. Physical observations occur every 30 seconds and are
non-atomic; neither the process detector nor the logs prove uninterrupted power
or the absence of every possible competing activity. Operator reservation is
still required. A violation revokes admission and interrupts the owned root;
cleanup retains the actual exit and stopped/unattempted accounting.

The root has its own process group. After revocation, shutdown uses the existing
180-second interrupt budget, followed if necessary by 10-second terminate and
kill budgets and bounded group-disappearance observation. The sleep inhibitor
also has bounded terminate/kill cleanup. These are cleanup limits, not a
whole-study time limit. Escalation is disclosed in the final physical record.
Log descriptors append only; each check authenticates the previously observed
byte prefix while permitting concurrent growth. This detects observed-prefix
rewriting at checks, not every possible transient modification between samples.

Retained checks replay saved numerical evidence for equality; they do not create
new measurements or establish blinding. The result spans sessions, and fixed
workload order can confound workload/concurrency with session effects. Disclose
this and the prior exposure without post hoc adjustment or a single-session
claim. Completed reference cells are not replaced to improve H3. A second
interruption requires a separate review and adoption, not an automatic retry.
