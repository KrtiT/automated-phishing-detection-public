## Frozen identities and execution

The privacy-projected reports are reading copies, not the original hash-bound
execution inputs. Historical contracts still name the original hashes. The
frozen execution code deliberately does not accept a privacy projection as the
original file; no execution gate was relaxed for this publication.

Use the recorded frozen revision and authorized retained originals for historical
execution work. Public archive recomputation uses the separately authenticated
research release. Do not substitute a projected report to satisfy an original
execution pin. This publication itself authorizes no new research execution.

## Limits of removal

This review covers the current tracked publication, extracted Office parts,
PDF metadata/text/links, and all nine hash-authenticated research archives.
The audit records identify the patterns checked and any exceptions; they do not
guarantee that every possible private detail can be detected automatically.

**Previously published Git history has not been rewritten.** Earlier commits,
tags and their generated source archives can still expose the original machine
paths, personal commit email addresses and earlier copies of the education text.
Removing those copies requires a separate history migration and provenance map.
Deleting or replacing a release download cannot erase existing clones, caches
or third-party copies. This distinction is recorded rather than claiming that
current-file cleanup removes all historical exposure.
